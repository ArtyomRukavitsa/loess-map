# Деплой автопополнения из открытых источников (fn_crawl)

Обходит раздел «Науки о Земле» КиберЛенинки, отбирает статьи по теме и заводит их как обычные
задачи — дальше их подхватывает уже развёрнутая `fn-process`.

## Почему это дёшево

**Распознавание не запускается.** На КиберЛенинке текст статьи уже готов и лежит на странице.
Краулер кладёт его туда, куда обычно пишет OCR (`ocrtext/upload/<job>.json`, `complete: true`),
и создаёт задачу — `fn-process` видит готовый текст и сразу переходит к извлечению.

**Отсев бесплатный.** Заголовок и аннотация есть прямо на странице списка, поэтому статьи
скачиваются только те, что прошли фильтр: примерно **2,5 %** — около **1 700** из 70 610.

## 1. Создать функцию

| Параметр | Значение |
|---|---|
| Имя | `fn-crawl` |
| Среда выполнения | **`python311`** |
| Точка входа | **`index.handler`** |
| Память | **256 МБ** |
| Таймаут | **900 с** |
| Файлы | `index.py`, `requirements.txt` |

## 2. Переменные окружения

| Переменная | Значение |
|---|---|
| `BUCKET` | `loess-results` |
| `AWS_ACCESS_KEY_ID` | из `.secrets` |
| `AWS_SECRET_ACCESS_KEY` | из `.secrets` |

Необязательные: `LIST_PER_RUN` (400 страниц списка за запуск), `FETCH_PER_RUN` (40 статей),
`DELAY` (1.0 с — вежливая пауза), `TIME_BUDGET` (780 с), `LAST_PAGE` (3531).

## 3. Триггер

**Таймер**, cron `0/15 * * * ? *` (раз в 15 минут). Функция сама держит курсор в бакете
(`crawl/state.json`), поэтому каждый запуск продолжает с места остановки.

Публичный доступ не нужен — вызывает только таймер.

Оценка: перечисление 3 531 страницы ≈ 9 запусков, забор ~1 700 статей ≈ 43 запуска.
При таймере раз в 15 минут весь обход занимает примерно **13 часов**, дальше — только новинки.

## 4. Ручное управление

```bash
# сделать один шаг сейчас
curl -X POST "https://functions.yandexcloud.net/<ID>" -H "Content-Type: application/json" -d '{}'

# посмотреть прогресс, ничего не делая

# начать обход заново

```

Ответ: `{"page": …, "last_page": 3531, "candidates": …, "fetched": …, "stats": {...}, "done": false}`.

## 5. Как устроен отсев

Двухуровневый, иначе в выборку лезет вся геология — слова «стратиграфия», «литология»,
«датирование» одинаково употребимы и про конодонтов девона, и про лёссы.

- **Сильные признаки** (достаточно одного): лёссы, палеопочвы, педокомплексы, плейстоцен,
  голоцен, морены, межледниковья, криогенные явления, каспийские горизонты (хвалынский,
  хазарский), названия четвертичных горизонтов (лихвинский, микулинский, валдайский…),
  методы датирования, тефра.
- **Слабые** (нужно три и более): разрез, обнажение, скважина, мощность, терраса, аллювий…
- **Чужой период без признаков четвертички** (девон, юра, мел, палеозой…) — отклоняется.

Две ловушки, проверенные на живых данных и учтённые:
- **`loess`** — омоним статистического сглаживания LOESS;
- **«антропоген»** — в современных текстах почти всегда «антропогенный» (влияние человека),
  а не четвертичный период. Та же ловушка, что «лес» против «лёсс».

Составные признаки ищутся по всему тексту, а не подряд: «погребенные почвы» не содержит
подстроки «погребенн почв» из-за склонения.

## 6. Проверено перед деплоем

- разбор страницы списка: 20 статей, из каждой берутся слаг, заголовок, аннотация, год, авторы;
- разбор страницы статьи: все мета-теги на месте, текст — 63 882 символа на проверочной статье;
- полнота: четыре заведомо релевантные статьи проходят отсев;
- точность: 2,5 % на 200 случайных статьях из десяти разных мест раздела.
